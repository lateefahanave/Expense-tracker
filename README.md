# Expense Tracker

A simple expense tracker built while learning JavaScript and React.

## Features
- Add expenses
- Enter key support for adding expenses
- Load sample expenses from JSON
- React version of the app

## Tech Used
- JavaScript
- React
- Vite

## Learning Goals
This project was built to practice DOM manipulation, async fetch requests, and React component architecture.

## Next Improvements
